# Ручная проверка: web-клиент

Спека: [`2026-09-03-web-client-design.md`](../specs/2026-09-03-web-client-design.md). План: [`2026-09-03-web-client.md`](../plans/2026-09-03-web-client.md).

## Что проверялось

`go run ./cmd/api` (реальный backend + Postgres) и `npm run dev` (Vite dev-сервер) одновременно, прокси между ними.

## Прогон

```
$ curl localhost:8080/healthz              # backend напрямую
{"status":"ok"}

$ curl localhost:5173/api/v1/bosses        # через Vite-прокси
[{"boss_id":"shadow_hunter", ...}, ...]    # реальные данные с backend, не мок

$ curl -o /dev/null -w "%{http_code}" localhost:5173/
200
```

Прокси `/api/*` → `http://localhost:8080` работает: фронтенд получает реальные данные backend'а без CORS-обвязки.

## Явное ограничение этой проверки

**В этой среде выполнения нет браузера/инструмента для интерактивной проверки UI** — визуальный проход по всем 4 экранам (клик, ввод текста, просмотр рендера) не выполнен. Это прямо оговорено спекой как допустимый исход, а не как «протестировано»: код проверен на трёх уровнях — 23 компонентных теста (Vitest + React Testing Library, все состояния loading/error/success для каждого экрана и полный happy path в `App.test.tsx`), `npm run build` (TypeScript компилируется без ошибок), и сетевой уровень (прокси реально достаёт данные с живого backend, curl выше). Чего это не покрывает: реальную вёрстку, доступность с клавиатуры/скринридера, визуальные баги — это остаётся неподтверждённым до первого ручного прохода в браузере.

## Статус

Пройдено настолько, насколько позволяет среда. `npm test` — 23/23, `npm run build` — чисто, сетевой путь через прокси подтверждён curl'ом. Браузерная проверка — открытый пункт, не забыт, а явно вынесен сюда как то, что нужно сделать вам (или в среде с браузером) перед показом кому-либо.
