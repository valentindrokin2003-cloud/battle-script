## Порядок выполнения

Boss-эндпоинты (п.2–3) не зависят ни от чего нового — первые. Tactics (п.4–5) зависят от уже готовых `BasicModerator`/`ClassifyWithFallback`/`LocalHeuristicClassifier`. Battles (п.6–7) зависят от `ValidateIntentClassification`/`RunBattle`. Router (п.8) и интеграционный тест (п.9) — последние, объединяют всё. `main.go` (п.10) — последний, чисто сборочный код.

## Валидация

```bash
cd backend && make check   # fmt-check, vet, golangci-lint, go test ./... -race
```

Плюс ручной прогон после п.10:

```bash
cd backend && go run ./cmd/api &
curl localhost:8080/healthz
curl localhost:8080/api/v1/bosses
curl -X POST localhost:8080/api/v1/tactics/classify -d '{"hero_class":"mage","boss_id":"frost_warden","prompt_text":"используй ледяной шар только в фазе щита босса, в остальное время атакуй слабейшего"}'
```

Результат этого прогона идёт первой записью в `docs/superpowers/verification/`.
